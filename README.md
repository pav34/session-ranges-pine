# Session Ranges + Alerts (TradingView, Pine Script v6)

Draws the Asia, London and New York session ranges on any chart, extends the Asia high and low, and alerts when price breaks them after Asia closes.

<!-- Drag SessionRanges-demo.mp4 onto this line while editing on GitHub -->

## Features

- Session boxes with the live range size for Asia, London and New York
- Asia high and low extended until the next Asia session
- Breakout markers and alerts, on candle close or intrabar
- Range table with adjustable text size
- Session times are read in New York time, so they stay correct through daylight-saving changes
- Sessions, times and colours are all adjustable

## Install

1. Open the Pine Editor in TradingView.
2. Paste `SessionRanges.pine`, click **Save**, then **Add to chart**.
3. For alerts: **Create alert → Condition: Sessions → Any alert() function call**. Indicator alerts need a paid TradingView plan (Essential or higher); the indicator itself works on the free plan.
